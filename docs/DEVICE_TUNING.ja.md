# デバイストuningチェックリスト

OffscreenCanvasのような重いレンダラー作業を有効にする前に、このチェックリストを使用してください。デスクトップエミュレーションではなく、実際のデバイス上で展開されたPWAに対して実行します。

## デバイス

- iOS Safari: 現在の安定版iOS、低電力モードオフおよびオン。
- Android Chrome: 中程度のデバイス上の現在の安定版Chrome。
- オプション: フレームp95が閾値に近い場合、古いAndroid Chrome。

## スモークフロー

1. 展開されたPWAを開く。
2. URLフィールドおよびWeb Share Targetを通じてライブストリームを開始する。
3. タップして再生、ポーズ、およびカスタムコントロールが使用可能であることを確認する。
4. LIVEモードがシークバーを隠し、リプレイモードがそれを有効にすることを確認する。
5. Media Sessionメタデータが表示され、サポートされている場所で再生/一時停止アクションが機能することを確認する。
6. Wake Lockがフォアグラウンド中に画面を覚醒させ、停止時に解除されることを確認する。
7. `?perf=1`を開き、アクティブチャットで少なくとも3分間視聴する。

## パフォーマンスゲート

HUDから`fps`、`frameP95`、`frameP99`、`longTasks`、`active`、および`dropped`を記録します。実際のデバイスが以下のいずれかを示さない限り、現在のCanvas2Dレンダリングを維持します：

- `frameP95 > 33ms`が30秒以上続き、`active < maxActive`である場合、または
- 通常のチャットバースト中に長タスクの成長が繰り返される場合、または
- コメントが流れている間にタッチ/ビデオコントロールが明らかに遅延する場合。

その場合のみ、OffscreenCanvasまたはワーカー側のラスタライズをプロトタイプします。プロトタイプには、上記のデバイスでの前後のHUDキャプチャが含まれ、絵文字レンダリング、スーパーチャットの色、またはリストのスクロールが後退しないことが必要です。

## チューニングデフォルト

- 新しいレンダラーアーキテクチャを追加する前に、`renderScalePct`、`spawnPerFrame`、または`maxActive`を下げることを優先します。
- `renderScalePct`は、iOSとAndroidの両方の測定が分割をサポートしている場合にのみ、デバイス固有のデフォルトを維持します。
- 候補のリリースノートに最終値とスクリーンショットを文書化します。
